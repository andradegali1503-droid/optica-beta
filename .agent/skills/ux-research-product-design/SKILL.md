# UX Research & Product Design Skill

## Optical Business Journey & Task Analysis
1. **The Optometric Exam Journey:**
   - Patient arrives -> Check-in with 1 click -> Gabinete entry -> Quick recall of previous prescription -> Real-time comparison with new trial lens -> Final prescription generation -> Automatic handover to optical sales dispenser.
2. **Cognitive Load Minimization:**
   - Default values for axis ($180^\circ$ or $90^\circ$ common presets).
   - Auto-calculate near vision when distance sphere + addition are provided.
   - Prevent accidental prescription overwrites with explicit save/sign confirmations.
3. **Ergonomic Shortcuts:**
   - Pressing `Tab` moves naturally between SPH -> CYL -> AXIS -> ADD -> DP.
   - Global search (`Ctrl+K` / `Cmd+K`) instantly available across all views.
