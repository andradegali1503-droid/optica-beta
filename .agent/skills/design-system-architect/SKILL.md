# Design System Architect Skill

## Token Architecture
1. **Color Tokens:**
   - Primary: Medical Teal (`#0d9488` / Teal-600) representing healthcare accuracy and trust.
   - Neutral Base: Slate neutrals (`#020617` to `#f8fafc`) for crisp, non-fatiguing data reading.
   - Semantic Status: Emerald (confirmado/en stock), Amber (precaución/stock mínimo), Rose (urgente/cancelado/agotado), Sky (informativo).
2. **Typography Hierarchy:**
   - Display: Inter / Geist Sans bold for section titles.
   - Body: 14px / 13px regular for maximum scan speed in clinical rows.
   - Numeric Figures: `font-mono` / `tabular-nums` for optical diopters and financial currencies.
3. **Spacing & Radii:**
   - Spacing: 4px baseline scale (`p-1`, `p-2`, `p-4`, `p-6`).
   - Radii: 8px to 12px (`rounded-lg`, `rounded-xl`) for contemporary software elegance without childish over-rounding.
